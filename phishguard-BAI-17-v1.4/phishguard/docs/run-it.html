Getting PhishGuard running

Six steps, about five minutes. You do not need to know anything about the project first, and you do not need Docker.

Your computer
1

Put the project folder somewhere you can find it

You have a file called phishguard-BAI-17.zip. Unzip it, then move the folder it produces onto your Desktop so the next steps are short.

  1. Right-click the zip file → Extract All… → Extract.
  2. You now have a folder called phishguard. Drag it to your Desktop.
  1. Double-click the zip file. macOS unzips it beside the file.
  2. You now have a folder called phishguard. Drag it to your Desktop.
Check you're right

Open the folder. You should see files named start.py, README.md and pyproject.toml. If you only see one folder inside, go into it — that's the real one.

2

Open a terminal

Terminal — a window where you type commands instead of clicking. It's the black-or-white text window you've seen in films. Nothing you type here can break your computer.

  1. Open the phishguard folder.
  2. Click once in the empty white space inside the folder, so nothing is selected.
  3. Hold Shift and right-click that empty space.
  4. Choose Open PowerShell window here — or Open in Terminal on Windows 11.

A window opens with white or blue text ending in >. That's your terminal, and it is already pointed at the right folder.

  1. Open Finder and find the phishguard folder on your Desktop.
  2. Right-click the folder itself.
  3. Choose Services → New Terminal at Folder.

A window opens with text ending in %. That's your terminal, and it is already pointed at the right folder.

I don't see "New Terminal at Folder"

It's switched off by default on some Macs. Turn it on: System Settings → Keyboard → Keyboard Shortcuts → Services → tick New Terminal at Folder.

Or: open Terminal from Applications → Utilities, type cd (with a space after it), then drag the phishguard folder into the window and press Enter.

3

Check you have Python

Type this and press Enter.

Type python --version
Type python3 --version
What counts as fine

Any number 3.10 or higher. So 3.10, 3.11, 3.12, 3.13 — all good. Move on to step 4.

It said "command not found" or "not recognized"

Python isn't installed, or Windows can't see it. Download it from python.org/downloads and run the installer.

On the first installer screen, tick "Add python.exe to PATH" before clicking Install. Almost everyone misses this, and it is the reason the command isn't found.

Then close the terminal, open a new one (step 2 again), and retry.

It said 3.9 or lower

Too old for this project. Install a current version from python.org/downloads, then use that version's name in step 4 — for example python3.12 start.py.

4

Run the one command

This is the only command that matters. It sets everything up for you.

Type python start.py
Type python3 start.py

You'll watch it work through five steps. This is what it looks like:

Why it takes a minute — step 4 builds the phishing detector from scratch on your machine. It happens once. Every time after this, the command takes seconds.

You're done when

The terminal stops at step 5 and shows a web address. It looks frozen — it isn't. It's the server running. Leave this window open.

The install step failed

Almost always no internet. Connect, then run the same command again — it picks up where it left off.

It stopped and mentioned memory

Your machine is short on memory. Close other programs, then train a smaller model:

.venv/bin/phishguard train --n 4000 --save on Mac, or .venv\Scripts\phishguard train --n 4000 --save on Windows.

Then run the start command again.

Something else went wrong

The script stops with a plain sentence saying what happened and the command that fixes it. Read the last few lines — the answer is there.

If it still won't go, copy the red text and send it to me.

5

Open it in your browser

Your browser should open by itself. If it doesn't, open one and type this address in yourself.

Address http://localhost:8000

localhost — your own computer. Nothing is going over the internet and nothing is public; this page only exists on your machine.

Paste this into the box at the top right, then press Connect:

Key dev-admin-key-change-me
You're in when

The small dot next to the box turns green.

The page won't load at all

Go back to the terminal. If it has stopped and returned to a prompt, the server exited — scroll up to see why. If it's still sitting at step 5, the server is fine; check the address is exactly http://localhost:8000.

6

Try it

Choose an example from the dropdown, then press Assess message. Try these three in order.

Choose this exampleWhat you'll get
Credential phishing (obvious) BLOCK — with the reasons listed in plain English
Legitimate internal mail ALLOW — nothing wrong with it
Cloned brand template (hard) BLOCK — the one worth understanding

The example to show your examiner

Cloned brand template is what this whole project is about. Its text is PayPal's real password-reset email, copied word for word — which is exactly what real phishing kits do. Only the link and the sending domain were changed.

Assess it, then press Compare with a text-only filter:

ReaderScoreWhat it sees
Text-only filter0.52Reads the words. The words are PayPal's own, so it cannot decide.
PhishGuard0.99The link goes to paypal-secure-mail.com, a 41-day-old domain that is not PayPal's, from a sender never seen before, sending in a burst. BLOCK.

None of what gave it away is in the words. That single screen is the argument for the entire design. For the second half of the argument, load Compromised internal account (hard): one reader is fooled, the other three are not, so PhishGuard sends it to a human (REVIEW) instead of guessing.

Stopping it: press Ctrl + C in the terminal window.

Starting it again later: repeat steps 2 and 4. It'll be quick — the model is already built.

If anything at all misbehaves: run .venv/bin/phishguard doctor --self-test (Mac) or .venv\Scripts\phishguard doctor --self-test (Windows). It checks every part and tells you exactly what's wrong.
